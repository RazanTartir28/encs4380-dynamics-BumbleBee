1. System Overview

This project applies closed-loop PID speed control to the BumbleBee Micromouse robot. An ESP32 calculates the controller output, a DRV8833 motor driver applies PWM to an N20 DC gearmotor, and a magnetic encoder measures the motor speed.

The simulation represents one wheel. The robot uses two motors, which can be controlled independently.

DEMO — NOT MEASURED: The motor's advertised voltage and speed are known. Plant gain K, time constant τ, encoder resolution and PID gains are currently estimated or illustrative. Simulation results must not be presented as real experimental measurements.

2. Control System Architecture

Target RPM → ESP32 PID → PWM → DRV8833 → N20 Motor → Encoder Feedback → ESP32

The encoder measures the actual speed. The controller compares the measured RPM with the desired RPM and adjusts the PWM duty cycle to reduce the speed error.

3. Motor Plant Model

A first-order approximation is used:

G(s) = K / (τs + 1)

K represents motor speed gain in RPM per percent PWM, while τ represents the time constant in seconds.

The numerical simulation uses Euler integration:

y[k+1] = y[k] + Δt × (K × u[k] − y[k]) / τ

Demo assumptions: K = 530 / 100 = 5.3 RPM per % PWM, assuming 530 RPM at 100% PWM without load. τ = 0.35 s is an illustrative value, not a measurement.

4. PID Controller

The controller uses proportional, integral and derivative actions with PWM saturation from 0% to 100%. Conditional anti-windup limits integral accumulation. The derivative acts on measured speed.

For the nominal first-order plant with a PI controller (Kd = 0), the closed-loop characteristic equation is:

τs² + (1 + K×Kp)s + K×Ki = 0

The nominal damping ratio is:

ζ = (1 + K×Kp) / (2√(τ×K×Ki))

This damping-ratio expression applies to the unsaturated continuous-time PI model. It is not a general formula for PID with nonzero Kd or for saturated behavior.

9. Conclusion



This educational prototype demonstrates closed-loop motor
speed control for BumbleBee Micromouse using a first-order
motor model and a PID controller. It provides numerical
simulation, controller tuning, speed tracking, PWM
visualization and performance evaluation.




The simulated results are preliminary. Experimental
identification and hardware validation are required
before the final controller can be considered verified.
