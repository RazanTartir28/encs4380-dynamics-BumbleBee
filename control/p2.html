Understanding Sensor Delay

Explore how sensor speed changes feedback and the PID-controlled response.

1. Ideal Sensor (τs = 0 s)

The measured output follows the true plant output without sensor delay, so the two curves overlap.

Compare the two curves at τs = 0 s.

2. Slow Sensor (τs > 0 s)

The sensor behaves as a first-order system. During a rising response, its reported value initially lags behind the true output. Increasing τs generally increases this delay.

3. Why Overshoot Can Increase

The PID uses the measured output to calculate error: e = setpoint − measured output. A delayed reading can keep the controller requesting a strong action even after the true output has risen substantially.

4. Why Oscillations Can Occur

Delayed feedback can make the controller react too late and repeatedly overcorrect. Oscillation depends on PID gains, plant dynamics, sensor delay, and control limits.

5. Try It Yourself

Choose the first-order plant with Kp = 1, Ki = 1, Kd = 0, and setpoint = 0.5. Compare τs = 0, 0.5, and 2 s. Watch the true and measured curves, peak, and settling behavior.

6. Simulation Note

The applied control is limited to 0–0.8. This can affect overshoot, oscillation, and whether the output reaches the setpoint. Not every gain setting will oscillate.
