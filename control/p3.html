Digital feedback loop

Setpoint r → sampled error e[k] → digital PID (every Ts) → saturation → held control u → plant → output y → feedback.

The plant is integrated with Euler every 0.002 s. The controller updates only at the selected Ts and holds each command between samples (zero-order hold). Anti-windup uses conditional integration.

Performance

Metrics use the requested setpoint, a 10–90% rise time, and a ±2% settling band. N/A means the result was not established within this simulation window. Dashed comparison: identical settings with Ts = 0.01 s.
