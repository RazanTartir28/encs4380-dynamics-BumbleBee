Mission: tune a hidden plant

A random first-order plant is generated for each challenge, inspired by Homework 1 Module 4. Its gain K and time constant τ stay hidden. Adjust the PID gains to satisfy all three specifications. The plant is simulated numerically using Euler integration.

Target specifications

Overshoot
≤ 10%
Settling time (±2%)
≤ 5.0 s

≤ 1% of setpoint

Setpoint = 1.0; simulation duration = 25 s. Final error is estimated over the last second, and a non-settling or unstable response fails.

Your PID controller

Controller output is limited to ±10. Conditional anti-windup prevents the integral term from growing while saturated. Derivative acts on measured output to avoid setpoint kick.

How the challenge works

The hidden plant is G(s) = K/(τs + 1). The state evolves as dy/dt = (K·u − y)/τ. Every 0.002 s, Euler integration advances the output, and the PID computes a bounded command. The overshoot is based on the peak relative to the setpoint. Settling time is the earliest time after which every remaining sample stays within ±2%. A run passes only if all three requirements pass. The score awards 40 points for overshoot, 35 for settling, and 25 for final error.

This is a simulation challenge, not an identification tool. Plant parameters remain hidden throughout each round. New plant resets the challenge. Changing gains and rerunning preserves the same plant.
