Parameter Guide

Increasing m lowers natural frequency. Increasing b increases damping. Increasing k raises natural frequency.

ζ = b/(2√mk)
ωn = √(k/m)

1. Mathematical Model

Mass–spring–damper system with a unit-step force. The plotted output is displacement x(t), with final value x(∞) = 1/k.

Differential Equation
mẍ + bẋ + kx = F(t)
Transfer Function
G(s) = 1 / (ms² + bs + k)
Standard Parameters
ωn = √(k/m)
ζ = b/(2√mk)
Step Response
x(t) = (1/k) × unit-step shape

2. Step Response

The curve and performance measures update with the selected parameters.

3. Poles in the s-Plane

Roots of s² + (b/m)s + k/m = 0. The poles determine the damping case and response shape.

4. State-Space Representation

With x₁ = x (displacement), x₂ = ẋ (velocity), input F(t): ẋ = Ax + Bu and y = x₁ = Cx, where C = [1 0].
